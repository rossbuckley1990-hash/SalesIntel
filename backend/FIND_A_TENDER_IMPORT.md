# Find a Tender historical context

MiSi can retrieve published UK public-sector notice releases from the [Find a Tender OCDS API](https://www.gov.uk/government/publications/open-contracting). The source publishes its data under the Open Government Licence. This feed does not cover all organisations or the wider private market, and it does not prove buying intent, an unmaintained system, a legal breach, or a supplier's performance. A buyer's published address need not be the service site.

Refresh from the Evidence interface, or call `POST /api/public-sources/find-a-tender/refresh` with `{}`. This examines up to two pages from the most recent seven-day update window. The default filter looks for fire/security systems and maintenance terminology in historical award or contract notices. Only releases with an identifiable buyer, publication date and direct notice link are imported. Counts describe scanned releases and matching source observations, not leads. Manual verification remains essential.

The response includes a frozen `updated_from` and `updated_to` plus `next_cursor` when there are further pages. To continue, call the same endpoint with those three values and keep any `keywords` unchanged. Each request fetches at most ten pages (the default is two); update windows are limited to 31 days. The server fetches each bounded batch before importing it, and re-importing the same source observation is deduplicated. A failed source request does not import a partial batch. Set `keywords` to a non-empty list of search terms for another subject; these use an inclusive match in the title or description, and produce observations categorised as `other`.

Updates are on demand; this connector does not install an automatic schedule or sweep every historical notice. Iterating through all pages and date windows takes time and is subject to the source's availability. Cross-source identity resolution and independent corroboration remain separate research steps.
