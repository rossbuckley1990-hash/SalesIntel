# MiSi Porcelain & Obsidian — visual review

These captures are from the actual local application using its existing workspace data. Keep them within the authorised local environment.

`before/` and `after/` contain matched 1440 × 900 desktop, 1024 × 768 tablet and 390 × 844 mobile screenshots for Today, Discover, a selected saved research lead, Customers, Opportunities and My Work. `after/search-interaction-desktop.png` shows the command palette. The customer and opportunity-list captures show the real empty states in this workspace; populated views were verified separately against isolated synthetic test data.

The screenshots can be regenerated using `MISI_DESIGN_ROOT=../design-review-v2` and `MISI_DESIGN_STAGE=after` with the frontend's reusable Playwright configuration.
