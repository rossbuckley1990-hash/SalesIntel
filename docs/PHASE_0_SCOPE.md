# Phase 0 Scope

The Phase 0 repository setup proves that both halves of SalesIntel can run locally and that the project has clear boundaries for secure future development.

## Included

- Next.js dashboard shell for SalesIntel
- FastAPI health endpoint
- Local SQLite configuration path
- Optional backend-only OpenAI structured analysis integration
- CSV/XLSX tracker upload and controlled mock source connector framework
- Synthetic sample data
- Basic frontend and backend tests
- Local development scripts and README

## Excluded

- Authentication and role-based access control
- Real pipeline ingestion
- Real tender source connectors or live public-source integrations
- Automated OpenAI calls outside explicit backend analysis requests
- Forecasting algorithms
- Production deployment infrastructure
- Customer, prospect, or tender data
