# Sample Data

These files are synthetic examples for local development only. Do not add real Mitie, customer, prospect, financial, tender, or personal data to this directory.

- `pipeline_sample.csv`: small pipeline-style CSV for reference.
- `tender_signals_sample.csv`: small tender signal sample.
- `tracker_upload_sample.csv`: synthetic internal tracker upload sample for `POST /api/upload-tracker`.
- `tracker_upload_sample.xlsx`: XLSX version using alternate tracker-style headings and sparse optional fields.
- `real_tracker_template.csv`: header-only template for a real tracker import. Keep real filled-in files outside this repository.
